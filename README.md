# Simple Kanban Board App

A simple and clean Kanban board application built with React.

## Features

- Add new tasks with title and description
- Move tasks between columns (To Do, In Progress, Done)
- Delete tasks
- Responsive design that works on mobile and desktop
- Clean and modern UI

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) to view the app.

## Project Structure

- `src/App.jsx` - Main application component with Kanban board logic
- `src/App.css` - Styling for the application
- `src/index.js` - React entry point
- `src/index.css` - Global styles
- `public/index.html` - HTML template
- `public/manifest.json` - PWA manifest
- `package.json` - Project dependencies and scripts

## How to Use

1. **Add a task**: Fill in the task title and description, select a column, and click "Add Task"
2. **Move tasks**: Use the left/right arrows to move tasks between columns
3. **Delete tasks**: Click the trash icon to remove a task

## Technologies Used

- React 18
- React DOM
- CSS Grid for layout
- CSS Flexbox for component styling
